How Roll Yield Works

Backwardation (LONG): Front > NextPositive roll yield — futures curve slopes down. Roll profits as contracts converge to spot.
Contango (SHORT): Front < NextNegative roll yield — futures curve slopes up. Shorts benefit as contracts converge to spot.
Annualized YieldThe annualized percentage return from rolling futures positions, based on front-to-next spread.
Daily $/contractDollar value of the daily basis change per contract (using standard point values).
